---
title: "调用运行时"
---

`invoke` 命令组用于向已部署 Runtime 发送请求。常规用法是 `agentkit invoke run`：可以从 `agentkit.yaml` 解析 Runtime，也可以用 Runtime ID 或端点地址直接调用。

## invoke run

发送一条消息或一段 JSON 请求体到 Runtime。默认会按 Python SDK 兼容的请求格式发送，并在流式响应中输出答案文本；传入 `--raw` 可查看原始流式事件或 JSON 响应。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `[message]` | 要发送的用户消息；未传时必须提供 `--payload`。 | 无 |
| `--config-file <path>` | 用于解析 Runtime 的配置文件。不能与 `--runtime-id` 或 `--endpoint` 同用。 | `agentkit.yaml` |
| `-p, --payload <json>` | 要发送的 JSON 请求体；不能与 `[message]` 同用。 | 无 |
| `-h, --headers <json>` | 额外请求头，JSON 对象格式。 | 无 |
| `-r, --runtime-id <id>` | 按 Runtime ID 解析端点与鉴权信息。 | 无 |
| `-e, --endpoint <url>` | 直接调用指定端点；必须配合 `--apikey` 或 `--headers` 中的 `Authorization` 使用。 | 无 |
| `--region <region>` | Runtime ID 查询使用的区域；仅与 `--runtime-id` 同用。 | 自动检测 |
| `--a2a` | 在直接调用模式下强制使用 A2A JSON-RPC 请求。 | `false` |
| `--show-reasoning` | 流式输出中展示 LangChain `reasoning_content`。 | `false` |
| `--raw` | 输出原始流式事件或原始 JSON 响应。 | `false` |
| `--apikey <key>` | API Key 鉴权；直接端点调用时作为 Bearer key 使用。 | 无 |

```bash
agentkit invoke run "你好，介绍一下你自己"

agentkit invoke run \
  --runtime-id r-xxxxxxxx \
  --region cn-beijing \
  "总结本次会话"

agentkit invoke run \
  --endpoint https://runtime.example.com/run_sse \
  --apikey "$AGENTKIT_RUNTIME_API_KEY" \
  --payload '{"prompt":"生成三条测试用例"}' \
  --raw
```

直接端点模式不会读取 `agentkit.yaml`。使用 `--runtime-id` 时，CLI 会解析 Runtime 的端点与默认鉴权信息，因此不能同时传入 `--endpoint`，也不能用 `--apikey` 覆盖 Runtime ID 查询出的 `key_auth` 凭证。
