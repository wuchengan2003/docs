---
title: "管理模型网关"
---

`model-gateway` 命令组用于启用 AgentKit Model Gateway、接入模型提供方、创建调用方消费者，并生成调用示例。该命令也可使用别名 `mgw`。

<Warning>
模型网关会创建或修改云端网关、模型提供方与消费者资源。执行创建、更新或删除操作前，请确认区域、API Gateway 选择、模型访问地址和 API Key 的权限范围。
</Warning>

## model-gateway activate

启用 Model Gateway。若当前区域已有网关，命令会返回现有网关；否则创建新网关并等待其进入可用状态。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--apig-gateway-id <id>` | 使用指定 API Gateway 实例；省略时使用共享模式。 | 共享模式 |
| `-r, --region <region>` | 云区域。 | 自动检测 |
| `--json` | 输出原始 JSON。 | `false` |

```bash
agentkit model-gateway activate --region cn-beijing
agentkit mgw activate --apig-gateway-id apig-xxxxxxxx --json
```

## model-gateway provider create

创建模型提供方。模型提供方保存上游模型 API Base URL、协议、API Key 与模型名称。该命令也可写作 `model-gateway provider add`。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<name>` | 模型提供方名称。 | 必填 |
| `--base-url <url>` | 上游模型 API Base URL。 | 必填 |
| `--api-key <key>` | 上游模型 API Key；可重复传入多个。 | 必填 |
| `--model <name>` | 上游模型名称；可重复传入多个。 | 必填 |
| `--protocol <protocol>` | 上游协议：`openai` 或 `anthropic`。 | `openai` |
| `-r, --region <region>` | 云区域。 | 自动检测 |

```bash
agentkit model-gateway provider create ark \
  --base-url https://ark.cn-beijing.volces.com/api/v3 \
  --api-key ${ARK_API_KEY} \
  --model doubao-seed-2-1-pro
```

## model-gateway provider update

更新模型提供方。至少传入 `--base-url`、`--api-key`、`--model` 或 `--protocol` 之一；传入 `--api-key` 或 `--model` 时会替换对应列表。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<name>` | 模型提供方名称。 | 必填 |
| `--base-url <url>` | 新的上游模型 API Base URL。 | — |
| `--api-key <key>` | 替换上游模型 API Key 列表；可重复传入。 | — |
| `--model <name>` | 替换上游模型列表；可重复传入。 | — |
| `--protocol <protocol>` | 新的上游协议：`openai` 或 `anthropic`。 | — |
| `-r, --region <region>` | 云区域。 | 自动检测 |

```bash
agentkit model-gateway provider update ark --model doubao-seed-2-1-pro --model doubao-seed-2-1-lite
```

## model-gateway provider delete

删除模型提供方。

<Warning>
删除模型提供方会影响已授权到该提供方或模型的消费者。省略 `--yes` 时 CLI 会要求确认。
</Warning>

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<name>` | 模型提供方名称。 | 必填 |
| `-r, --region <region>` | 云区域。 | 自动检测 |
| `-y, --yes` | 跳过确认提示。 | `false` |

```bash
agentkit model-gateway provider delete ark --yes
```

## model-gateway consumer create

创建消费者。消费者持有访问模型网关的 API Key，并可通过授权和限流规则约束可访问的模型。该命令也可写作 `model-gateway consumer add`。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `<name>` | 消费者名称。 | 必填 |
| `--allow-model <provider[/model]>` | 授权访问的提供方或提供方下的模型；可重复。仅传提供方名称表示允许该提供方全部模型。 | 不设置授权规则 |
| `--tpm <tokens>` | 每分钟 token 限额。 | — |
| `--tpd <tokens>` | 每天 token 限额。 | — |
| `-r, --region <region>` | 云区域。 | 自动检测 |

```bash
agentkit model-gateway consumer create app \
  --allow-model ark/doubao-seed-2-1-pro \
  --tpm 60000 \
  --tpd 1000000
```

## model-gateway show-example

根据模型提供方与消费者生成调用示例。命令会选择消费者可访问的第一个模型，并输出对应协议的调用片段。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--model-provider <name>` | 模型提供方名称。 | 必填 |
| `--consumer <name>` | 消费者名称。 | 必填 |
| `--example <type>` | 示例类型：`curl`、`openai`、`anthropic` 或 `agentkit`。 | `curl` |
| `-r, --region <region>` | 云区域。 | 自动检测 |

```bash
agentkit model-gateway show-example --model-provider ark --consumer app --example agentkit
```
