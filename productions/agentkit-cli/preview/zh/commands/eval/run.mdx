---
title: "运行评测实验"
---

`eval run` 用于提交一次评测实验：选择一个评测集版本、一个或多个评估器版本，并对指定评测目标的某个版本执行评测。命令会按当前账号解析评测后端；在 TEA 后端中，`--dataset-version`、`--evaluator-version`、`--target-type` 与 `--target-version` 可精确控制版本。

```bash
agentkit eval run \
  --dataset qa-set \
  --dataset-version 0.0.8 \
  --evaluator relevance \
  --evaluator-version 0.1.2 \
  --target qa-agent \
  --target-version 1.0.0
```

## eval backend

查看并刷新当前账号解析到的评测后端。后端信息会写入本地缓存，后续 `eval` 子命令会复用该结果。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--json` | 输出原始 JSON。 | `false` |

```bash
agentkit eval backend
agentkit eval backend --json
```

评测后端解析会读取当前登录态与环境变量。需要强制刷新缓存或排查请求时，可把调试标志放在 `eval` 之后、子命令之前：

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--cache-refresh` | 忽略本地缓存，重新拉取评测后端信息。 | `false` |
| `--verbose` | 将完整 TEA 请求输出到标准错误，敏感 Cookie 会被遮蔽。 | `false` |

```bash
agentkit eval --cache-refresh backend
agentkit eval --verbose run --dataset qa-set --evaluator relevance --target qa-agent --dry-run
```

## eval run

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--dataset <id\|name>` | 评测集 ID 或精确名称，必填。 | 无 |
| `--dataset-version <id\|name>` | TEA 评测集版本 ID 或精确版本号，例如 `0.0.1`。未指定时使用当前版本。 | 当前版本 |
| `--evaluator <id\|name>` | 评估器 ID 或名称，必填，可重复指定多个。 | 无 |
| `--evaluator-version <id\|name>` | TEA 评估器版本 ID 或精确版本号；可重复，数量需与 `--evaluator` 对齐。 | 当前版本 |
| `--target <runtime name\|id>` | 被评测的运行时或评测目标，必填。 | 无 |
| `--target-type <n>` | TEA Source Eval Target 类型。 | `101` |
| `--target-version <version>` | TEA Source Eval Target 版本；未指定时使用版本列表中的最新版本。 | 最新版本 |
| `--name <name>` | 实验名称。 | `<评测集>-<时间戳>` |
| `--description <text>` | 实验描述。 | 无 |
| `--concurrency <n>` | 并发执行的用例数，必须为正整数。 | `5` |
| `--map <spec>` | 覆盖字段映射，可重复。TEA 与 Coze 后端语法不同，见下文。 | 自动映射 |
| `--dry-run` | 只打印将提交的请求，不真正发起实验。 | `false` |
| `-p, --project <name>` | 项目名称；TEA 后端会忽略该参数。 | `default` |
| `--json` | 输出原始 JSON。 | `false` |

```bash
agentkit eval run --dataset qa-set --evaluator relevance --target qa-agent --dry-run
```

<Note>
TEA 后端要求每个评估器都有明确版本。未传 `--evaluator-version` 时，CLI 会解析评估器当前版本；传入多个评估器时，也应按顺序传入对应数量的 `--evaluator-version`。
</Note>

## 字段映射

一次实验中有三层数据需要对齐：评测集字段、目标输入与输出、评估器输入。默认情况下，CLI 会把评测集主输入传给目标输入，并把目标输出传给评估器的答案字段；字段名称不一致时用 `--map` 覆盖。

TEA 后端使用箭头语法：

| 形式 | 含义 |
| --- | --- |
| `evaluator.<slot> <- dataset.<col>` | 评估器输入字段取自评测集字段。 |
| `evaluator.<slot> <- target.<field>` | 评估器输入字段取自目标输出字段。 |
| `target.<slot> <- dataset.<col>` | 目标输入字段取自评测集字段。 |

```bash
agentkit eval run \
  --dataset qa-set \
  --dataset-version 0.0.8 \
  --evaluator relevance \
  --evaluator-version 0.1.2 \
  --target qa-agent \
  --map "target.user_input <- dataset.question" \
  --map "evaluator.input <- dataset.question" \
  --map "evaluator.reference_output <- dataset.answer" \
  --map "evaluator.output <- target.actual_output"
```

Coze 后端保留等号语法：

| 形式 | 含义 |
| --- | --- |
| `评估器字段=数据集字段` | 评估器输入取自评测集字段。 |
| `评估器字段=target:目标输出` | 评估器输入取自目标输出字段。 |
| `target:目标输入=数据集字段` | 目标输入取自评测集字段。 |

```bash
agentkit eval run --dataset qa-set --evaluator relevance --target qa-agent \
  --map "output=target:actual_output" \
  --map "target:user_input=question"
```

## 提交前核对

首次运行建议加 `--dry-run`，确认解析出的评测集版本、评估器版本、目标版本与字段映射无误：

```bash
agentkit eval run \
  --dataset qa-set \
  --dataset-version 0.0.8 \
  --evaluator relevance \
  --evaluator-version 0.1.2 \
  --target qa-agent \
  --target-version 1.0.0 \
  --dry-run \
  --json
```

提交成功后返回实验 ID，可用 [`eval experiment show`](/productions/agentkit-cli/preview/zh/commands/eval/experiment) 跟踪实验状态，也可用 [`eval experiment results`](/productions/agentkit-cli/preview/zh/commands/eval/experiment) 查看结果。
