---
title: "管理自托管环境"
---

`env` 命令组用于为自托管沙箱项目创建和查看运行环境。当前支持 `self-host` 项目：先用 `sandbox init -t self-host` 生成配置，构建并创建沙箱 Tool，再用 `env create` 创建与该 Tool 绑定的 Runtime。

<Warning>
`env create` 会创建云端 Runtime，并要求 `.agentkit/sandbox.yaml` 中已经配置自托管环境凭证。该配置包含敏感密钥，应保存在本地或安全的密钥管理系统中，不要提交到代码仓库。
</Warning>

## env create

为当前自托管沙箱项目创建 Runtime。命令会读取 `.agentkit/sandbox.yaml` 中的 `self_host.sandbox.id` 作为 Tool ID，也可以通过 `--tool-id` 临时覆盖。创建进度与结果会写入 `.agentkit/environment.yaml`，并以 JSON 输出不含敏感环境变量的状态。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| `--force-new` | 即使本地已经有 `.agentkit/environment.yaml`，也创建新的环境资源。 | `false` |
| `--tool-id <id>` | 覆盖 `.agentkit/sandbox.yaml` 中的 `self_host.sandbox.id`。 | `self_host.sandbox.id` |

```bash
agentkit sandbox init -t self-host
agentkit sandbox config --set self-host-environment-base-url=https://gateway.example.com
agentkit sandbox config --set self-host-environment-id=env-xxxxxxxx
agentkit sandbox config --set self-host-environment-key=${SELF_HOST_ENVIRONMENT_KEY}
agentkit sandbox build
agentkit sandbox create
agentkit env create
```

## env status

查询当前自托管环境中的 Tool 与 Runtime 状态。命令会读取 `.agentkit/environment.yaml` 中保存的资源 ID，并刷新本地状态文件。

| 标志/参数 | 说明 | 默认值 |
| --- | --- | --- |
| _（无选项）_ | 该子命令不接受任何选项。 | — |

```bash
agentkit env status
```

## 自托管环境配置

自托管环境配置保存在 `.agentkit/sandbox.yaml` 的 `self_host` 块中。`sandbox init -t self-host` 会生成带占位符的配置；运行 `env create` 前必须替换 `environment_base_url`、`environment_id` 和 `environment_key`。

```yaml title=".agentkit/sandbox.yaml"
project_type: self-host
self_host:
  project_name: default
  poll_interval_seconds: 5
  environment:
    environment_base_url: https://gateway.example.com
    environment_id: env-xxxxxxxx
    environment_key: ${SELF_HOST_ENVIRONMENT_KEY}
  runtime:
    image_url: enterprise-public-cn-beijing.cr.volces.com/vefaas-public/agentkit-selfhostsandbox:runtime-0.0.1
    name: agentkit-selfhost-runtime
    role_name: AgentKit_Runtime_Default_ServiceRole
    cpu_milli: 2000
    memory_mb: 4096
    min_instance: 1
    max_instance: 1
    max_concurrency: 10
    timeout_seconds: 1200
    api_key_name: Authorization
```

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `project_type` | string | — | 自托管项目必须为 `self-host`。 |
| `self_host.project_name` | string | `default` | 创建 Tool 与 Runtime 使用的 AgentKit 项目。 |
| `self_host.poll_interval_seconds` | integer | `5` | 等待 Tool 或 Runtime 就绪时的轮询间隔。 |
| `self_host.environment.environment_base_url` | string | — | 自托管环境网关地址。 |
| `self_host.environment.environment_id` | string | — | 自托管环境 ID。 |
| `self_host.environment.environment_key` | string | — | 自托管环境密钥；`sandbox config --list` 会隐藏该值。 |
| `self_host.sandbox.id` | string | `sandbox create` 写入 | `env create` 使用的沙箱 Tool ID。 |
| `self_host.sandbox.name` | string | `sandbox create` 写入 | 沙箱 Tool 名称。 |
| `self_host.runtime.image_url` | string | 内置运行时镜像 | 自托管 Runtime 镜像地址。 |
| `self_host.runtime.name` | string | `agentkit-selfhost-runtime` | Runtime 名称前缀。 |
| `self_host.runtime.role_name` | string | `AgentKit_Runtime_Default_ServiceRole` | Runtime 使用的 IAM 角色。 |
| `self_host.runtime.cpu_milli` | integer | `2000` | Runtime CPU，单位为毫核。 |
| `self_host.runtime.memory_mb` | integer | `4096` | Runtime 内存，单位为 MB。 |
| `self_host.runtime.min_instance` | integer | `1` | Runtime 最小实例数。 |
| `self_host.runtime.max_instance` | integer | `1` | Runtime 最大实例数。 |
| `self_host.runtime.max_concurrency` | integer | `10` | 单实例最大并发数。 |
| `self_host.runtime.timeout_seconds` | integer | `1200` | Runtime 请求超时时间。 |
| `self_host.runtime.api_key_name` | string | `Authorization` | Runtime API Key 请求头名称。 |
