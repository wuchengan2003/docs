---
title: "Manage self-host environments"
---

The `env` command group creates and inspects runtime environments for self-host sandbox projects. The current flow supports `self-host` projects: generate the config with `sandbox init -t self-host`, build and create the sandbox Tool, then use `env create` to create the Runtime bound to that Tool.

<Warning>
`env create` creates a cloud Runtime and requires self-host environment credentials in `.agentkit/sandbox.yaml`. That configuration contains sensitive secrets; keep it local or in a secret manager, and do not commit it to source control.
</Warning>

## env create

Create the Runtime for the current self-host sandbox project. The command reads `self_host.sandbox.id` from `.agentkit/sandbox.yaml` as the Tool ID, or you can override it with `--tool-id`. Progress and results are written to `.agentkit/environment.yaml`, and the command prints JSON status without sensitive environment values.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `--force-new` | Create new environment resources even when `.agentkit/environment.yaml` already exists locally. | `false` |
| `--tool-id <id>` | Override `self_host.sandbox.id` from `.agentkit/sandbox.yaml`. | `self_host.sandbox.id` |

```bash
agentkit sandbox init -t self-host
agentkit sandbox config --set self-host-environment-base-url=https://gateway.example.com
agentkit sandbox config --set self-host-environment-id=env-xxxxxxxx
agentkit sandbox config --set self-host-environment-key=${SELF_HOST_ENVIRONMENT_KEY}
agentkit sandbox build
agentkit sandbox create
agentkit env create
```

## env status

Show the Tool and Runtime status for the current self-host environment. The command reads resource IDs from `.agentkit/environment.yaml` and refreshes the local state file.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| _(No options)_ | This subcommand does not accept options. | — |

```bash
agentkit env status
```

## Self-Host Environment Configuration

Self-host environment configuration lives in the `self_host` block of `.agentkit/sandbox.yaml`. `sandbox init -t self-host` writes a file with placeholders; replace `environment_base_url`, `environment_id`, and `environment_key` before running `env create`.

```yaml title=".agentkit/sandbox.yaml"
project_type: self-host
self_host:
  project_name: default
  poll_interval_seconds: 5
  environment:
    environment_base_url: https://gateway.example.com
    environment_id: env-xxxxxxxx
    environment_key: ${SELF_HOST_ENVIRONMENT_KEY}
  runtime:
    image_url: enterprise-public-cn-beijing.cr.volces.com/vefaas-public/agentkit-selfhostsandbox:runtime-0.0.1
    name: agentkit-selfhost-runtime
    role_name: AgentKit_Runtime_Default_ServiceRole
    cpu_milli: 2000
    memory_mb: 4096
    min_instance: 1
    max_instance: 1
    max_concurrency: 10
    timeout_seconds: 1200
    api_key_name: Authorization
```

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `project_type` | string | — | Must be `self-host` for self-host projects. |
| `self_host.project_name` | string | `default` | AgentKit project used when creating the Tool and Runtime. |
| `self_host.poll_interval_seconds` | integer | `5` | Polling interval while waiting for the Tool or Runtime to become ready. |
| `self_host.environment.environment_base_url` | string | — | Self-host environment gateway URL. |
| `self_host.environment.environment_id` | string | — | Self-host environment ID. |
| `self_host.environment.environment_key` | string | — | Self-host environment secret; `sandbox config --list` redacts this value. |
| `self_host.sandbox.id` | string | Written by `sandbox create` | Sandbox Tool ID used by `env create`. |
| `self_host.sandbox.name` | string | Written by `sandbox create` | Sandbox Tool name. |
| `self_host.runtime.image_url` | string | Built-in runtime image | Self-host Runtime image URL. |
| `self_host.runtime.name` | string | `agentkit-selfhost-runtime` | Runtime name prefix. |
| `self_host.runtime.role_name` | string | `AgentKit_Runtime_Default_ServiceRole` | IAM role used by the Runtime. |
| `self_host.runtime.cpu_milli` | integer | `2000` | Runtime CPU in milli-cores. |
| `self_host.runtime.memory_mb` | integer | `4096` | Runtime memory in MB. |
| `self_host.runtime.min_instance` | integer | `1` | Runtime minimum instances. |
| `self_host.runtime.max_instance` | integer | `1` | Runtime maximum instances. |
| `self_host.runtime.max_concurrency` | integer | `10` | Maximum concurrency per instance. |
| `self_host.runtime.timeout_seconds` | integer | `1200` | Runtime request timeout. |
| `self_host.runtime.api_key_name` | string | `Authorization` | Runtime API key request header name. |
