---
title: "Manage platform skills"
---

The `skill` command group manages skills on the AgentKit skill platform: list, show details, list versions, list skill spaces, and delete skills. The `skills` command group works with local skill packages.

## skill list

List skills.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `-r, --region <region>` | Volcengine region | None |
| `-p, --project <name>` | Project name | default |
| `--json` | Output raw JSON | `false` |

```bash
agentkit skill list
```

## skill show

Show a skill's details.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `<id>` | Skill id (required) | None |
| `-r, --region <region>` | Volcengine region | None |
| `--json` | Output raw JSON | `false` |

```bash
agentkit skill show sk-xxxxxxxx
```

## skill delete

Delete a skill.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `<id>` | Skill id (required) | None |
| `-r, --region <region>` | Volcengine region | None |
| `-y, --yes` | Skip the confirmation prompt | `false` |

```bash
agentkit skill delete sk-xxxxxxxx --yes
```

## skills secure

Generate secure Skill packages for managed agents from a local skills directory. By default, output is written to a sibling `<sourceSkillsDir>-secure` directory; pass `--force` to overwrite generated `SKILL.md` files that already exist.

| Flag / Argument | Description | Default |
| --- | --- | --- |
| `<sourceSkillsDir>` | Local skills directory. Required. | None |
| `-o, --output <dir>` | Output directory. | Sibling `<sourceSkillsDir>-secure` directory |
| `--force` | Overwrite existing generated `SKILL.md` files. | `false` |
| `--json` | Output raw JSON. | `false` |

```bash
agentkit skills secure ./skills

agentkit skills secure ./skills --output ./skills-secure --force --json
```
