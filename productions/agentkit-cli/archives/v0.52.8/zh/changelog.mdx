## 0.52.8 - 2026-08-26

- [沙箱命令](/productions/agentkit-cli/preview/zh/commands/sandbox)优化 Claude self-hosted sandbox 流程：`sandbox init -t self-host` 将 Anthropic 环境和 Runtime 配置写入 `.agentkit/sandbox.yaml`，`sandbox create` 先创建 `Private` Tool 并回写 `self_host.sandbox`，`env create` 复用该 Tool 创建 Runtime，也可通过 `--tool-id` 指定已有 Tool。
- [沙箱配置](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-config)统一将默认 Tool 标识保存到 `tool_info`，并在 `sandbox config --list` 中脱敏 `self-host-environment-key`；旧版配置中的 Tool 标识会迁移到新结构。
- [沙箱创建](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-create)在启用 `--network-private` 且未提供完整 VPC 和子网配置时，可交互选择可用 VPC 与子网并写回 `.agentkit/sandbox.yaml`。
- [技能命令](/productions/agentkit-cli/preview/zh/commands/skill)新增 `skills secure <sourceSkillsDir>`，可从本地 Skill 目录批量生成仅包含公开元数据和沙箱调用流程的安全 Skill，支持自定义输出目录、覆盖生成和 JSON 输出。
