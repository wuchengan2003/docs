## 未发布

当前没有未发布的公开变更。

## 0.52.8 - 2026-08-26

- [自托管沙箱](/productions/agentkit-cli/preview/zh/commands/sandbox)改为以 `.agentkit/sandbox.yaml` 保存 Anthropic 环境、Runtime 配置和已创建的沙箱工具信息；`sandbox init -t self-host` 不再生成 `.env` 与 `.env.example`，`env create` 会基于 `self_host.sandbox.id` 或 `--tool-id` 创建 Runtime。
- [沙箱创建](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-create)在启用 `--network-private` 且缺少完整 VPC 或子网配置时，会引导选择当前账号与地域下的可用 VPC 和子网，并把结果写回 `.agentkit/sandbox.yaml`。
- [沙箱配置](/productions/agentkit-cli/preview/zh/commands/sandbox#sandbox-config)将通用工具标识迁移到 `tool_info`，自托管沙箱工具标识迁移到 `self_host.sandbox`；旧配置会在读取时自动迁移，`self-host-environment-key` 在列表输出中会被脱敏。
- [技能命令](/productions/agentkit-cli/preview/zh/commands/skill)新增 `skills secure <sourceSkillsDir>`，可从本地 Skill 目录批量生成托管智能体侧使用的安全壳 Skill，并支持 `--output`、`--force` 与 `--json`。

## 0.51.1 - 2026-08-06

- 修复 BytePlus VikingDB [知识库操作](/productions/agentkit-cli/preview/zh/commands/knowledge)以及[迁移](/productions/agentkit-cli/preview/zh/commands/migrate)上传路径。
