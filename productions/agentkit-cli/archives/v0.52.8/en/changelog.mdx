## Unreleased

There are currently no unreleased public changes.

## 0.52.8 - 2026-08-26

- [Self-hosted sandboxes](/productions/agentkit-cli/preview/en/commands/sandbox) now store Anthropic environment settings, Runtime configuration, and the created sandbox tool information in `.agentkit/sandbox.yaml`; `sandbox init -t self-host` no longer generates `.env` or `.env.example`, and `env create` creates the Runtime from `self_host.sandbox.id` or `--tool-id`.
- [Sandbox creation](/productions/agentkit-cli/preview/en/commands/sandbox#sandbox-create) now guides VPC and subnet selection when `--network-private` is enabled without complete network configuration, then writes the selected values back to `.agentkit/sandbox.yaml`.
- [Sandbox configuration](/productions/agentkit-cli/preview/en/commands/sandbox#sandbox-config) migrates general tool identifiers to `tool_info` and self-hosted sandbox tool identifiers to `self_host.sandbox`; legacy entries migrate on read, and `self-host-environment-key` is redacted in list output.
- [Skill commands](/productions/agentkit-cli/preview/en/commands/skill) added `skills secure <sourceSkillsDir>` for bulk-generating secure wrapper Skills for managed agents from local Skill directories, with `--output`, `--force`, and `--json`.

## 0.51.1 - 2026-08-06

- Fixed missing Runtime assets in standalone distributions so files required by the [build, launch, and release workflow](/productions/agentkit-cli/preview/en/commands/build) are installed with the CLI.

## 0.51.0 - 2026-08-05

- Added `config`, `build`, `launch`, `status`, and `release` for a staged lifecycle from [project configuration](/productions/agentkit-cli/preview/en/commands/config) through [release](/productions/agentkit-cli/preview/en/commands/release).
- Expanded [sandbox commands](/productions/agentkit-cli/preview/en/commands/sandbox) with additional tool creation, Dashboard, and terminal management.
- Fixed BytePlus VikingDB [knowledge operations](/productions/agentkit-cli/preview/en/commands/knowledge) and the [migration](/productions/agentkit-cli/preview/en/commands/migrate) upload path.

## 0.50.9 - 2026-08-03

- Added global `--provider`, the top-level [`config`](/productions/agentkit-cli/preview/en/commands/config) command, and region selection for init, Harness, and migration.
- Completed BytePlus project switching, MCP service mapping, build images, and [migration](/productions/agentkit-cli/preview/en/commands/migrate).

## 0.50.8 - 2026-07-31

- Added `deploy config --provider` for selecting the cloud provider when generating [`agentkit.yaml`](/productions/agentkit-cli/preview/en/agentkit-yaml).
- Switched BytePlus [deployments](/productions/agentkit-cli/preview/en/commands/deploy) to the corresponding base images.

## 0.50.7 - 2026-07-31

- [Frontend SSO deployment](/productions/agentkit-cli/preview/en/workflows/frontend-sso) can discover existing serverless gateways across projects.

## 0.50.6 - 2026-07-31

- Automatically created gateways in [Frontend SSO deployment](/productions/agentkit-cli/preview/en/workflows/frontend-sso) now include their network specification.

## 0.50.5 - 2026-07-31

## 0.50.4 - 2026-07-30
